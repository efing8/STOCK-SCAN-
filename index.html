Your data

Backups & settings

Export, import and secure your inventory data.

Load starter inventory

Adds the products from the 11/17 sheet: name, quantity, and a Chases or Fillers category, plus a photo when the product is known. Prices are not imported. Products already in this browser are skipped, so tapping again does not create duplicates.

Download inventory as CSV

Open stock counts in Excel or Google Sheets. Photos are not included — use the JSON backup to keep pictures.

Import products from CSV

Add products in bulk or update existing ones by matching barcode/SKU. Supports name, barcode, SKU, quantity, minimum, category, location and notes.

Full backup (JSON)

Save every product, its photo, and every inventory transaction to one file. Recommended regularly.

Restore a backup

Restore a previous StockScan JSON backup. This replaces the inventory currently on this device.

Important: This free version does not synchronize different phones. Your data stays in this browser on this device; browser-data clearing, private browsing, and changing devices can result in data loss. Export a backup regularly. For a shared team inventory, a cloud database is needed.

Delete all local inventory

Erase products and activity permanently from this browser.
